Multiplayer counts from launch on 30 Nov 2026; testers' quizzes are left out. Quizzes: a quiz starts at kick-off, finishes when every game is played, and is given up when the host ends it early (unique = host devices). Players: everyone in the room at kick-off, counted as finished if still there at the end (unique = devices).

Total counts every time it happened, replays included. Unique counts each device once in the period shown (once per day, week or month, and once for the whole range in the table). Finished = played to full time without giving up; Gave up is counted separately. Finished % = finished ÷ started. Visits for all games = visits to the site (a new tab or session); for a game = times its page was opened. Site visit totals start on 18 Nov and game page counts on 23 Nov; unique visits before then count the devices that played. Replays started and replays given up are counted from 23 Nov. Test puzzles are never counted.
